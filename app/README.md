# Flutter Android controller

See the [root README](../README.md) for installation, pairing, permissions,
protocol, tests and limitations. Run Flutter commands from this directory.
The runnable target is Android API 24+ with an HC-05 Classic SPP radio; iOS is
not supported. No physical device validation has been performed.

Tap **Start demo** to test hold/release, STOP and simulated command feedback
without pairing, permissions or a robot. A top-view robot advances, reverses and
pivots with the controls; release/STOP freezes it. The preview is illustrative
and respects reduced-motion settings. Tap **Exit demo** before connecting
to real hardware. The screenshot capture command is documented in the root README.
